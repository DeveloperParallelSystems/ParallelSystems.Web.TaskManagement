Plan, assign, review, and deliver work across teams.

Common workflow for all teams

Backlog → To Do → In Progress → Ready for Review → In Review → Approved → [Ready for Release → Released] → Completed. If review fails, return work to the implementer using Failed Review, then Ready for Re-Review. Blocked and Cancelled are exception states. Release steps are optional.
